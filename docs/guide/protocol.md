# 协议规则

请求数据格式：`application/json`（POST 请求体）；GET 查询类接口将认证参数放在 URL query 上

返回数据格式：JSON，统一响应包络

```json
{ "code": 0, "message": "ok", "data": { } }
```

- `code` 为 `0` 表示成功，其它值均为失败，失败原因见 `message`
- `data` 为业务数据，仅成功时返回
- 响应不附带签名：请求认证已覆盖请求方向，响应回传在同一 TLS 连接内；
  安全关键通道是异步通知（Webhook），由平台私钥签名

签名算法：RSA2（SHA256WithRSA），签名放在 JSON body 参数内，详见 [RSA2签名算法](/sign/rsa.html)

字符编码：UTF-8

其它约定：

| 项目 | 说明 |
|---|---|
| 网关地址 | `https://你的网关地址`（下文以 `{site_url}` 表示） |
| 商户ID（pid） | 商户后台「安全设置」页查看 |
| 商户密钥 | RSA2 密钥对：公钥保存在商户后台，私钥商户自行保管（面板可一键生成） |
| 认证方式 | 每次请求携带 `pid` + `sign` + `sign_type=RSA2` |
| 时间戳校验 | `timestamp`（Unix 秒）**必填**，与服务器偏差超过 300 秒拒绝（防重放） |
| 下单幂等 | 同一商户同一 `out_trade_no` 重复下单返回原订单 |
| 退款幂等 | 同一商户同一 `out_refund_no` 重复提交返回原退款单 |
| 验证顺序 | 商户状态 → 签名与时间戳 → 平台开关（如 API 支付/退款开关） |

接入前准备：

1. 商户后台「安全设置」一键生成（或自行生成后上传）RSA2 密钥对，保存好私钥；
2. 记下 `pid` 与平台公钥（平台公钥用于验证平台的异步通知签名）。
